# Guide de l’espace de gestion — pour les bénévoles de l’ASLF

Ce guide s’imprime sur deux pages. Il n’y a rien à installer : tout se fait depuis un
navigateur (ordinateur, tablette ou téléphone).

## Se connecter

1. Ouvrez l’adresse du site suivie de **/admin**, par exemple `www.aslf-france.org/admin`.
2. Tapez le mot de passe de l’association, puis **Se connecter**.
3. Vous restez connecté 30 jours sur cet appareil.

Mot de passe oublié : demandez-le à la personne qui s’occupe du site.

## Publier un article

1. Cliquez sur le bouton vert **Écrire un nouvel article**.
2. Remplissez les étapes dans l’ordre :
   1. **Le titre** — une phrase courte.
   2. **Le résumé** — deux ou trois phrases.
   3. **La photo principale** — bouton **Choisir une photo**. Les photos de téléphone
      sont réduites automatiquement, inutile de les retoucher.
   4. **Le texte** — écrivez, ou collez depuis Word ou un e-mail. Les boutons au-dessus du
      texte servent à mettre en **gras**, ajouter un **intertitre**, une **liste**, un **lien**
      ou une **photo** au milieu du texte.
   5. **Où ranger l’article** — dans le doute, laissez **Actualités**.
   6. **En plus** (facultatif) — d’autres photos, une vidéo YouTube, la signature, une date
      de publication programmée.
3. Cliquez sur **Aperçu** pour voir le résultat sans rien publier.
4. Cliquez sur **Publier sur le site**. Un écran confirme « C’est en ligne ! ».

**Enregistrer sans publier** garde l’article en brouillon : il n’est pas visible sur le site.

Si la page se ferme par erreur, rouvrez l’article : l’éditeur propose de **reprendre le
texte** non enregistré.

## Modifier ou retirer un article

- Dans **Articles**, cliquez sur le titre (ou **Modifier**), changez ce qu’il faut, puis
  **Enregistrer les modifications**.
- **Retirer du site** remet l’article en brouillon, sans le supprimer.
- **Supprimer** le place dans la **Corbeille** pendant 30 jours. Pour le récupérer : onglet
  **Corbeille**, puis **Remettre**.

## Lire les messages des visiteurs

Les messages envoyés depuis la page **Contact** du site arrivent dans **Messages**. Une
pastille rouge indique le nombre de messages non lus. **Répondre par e-mail** ouvre votre
messagerie avec l’adresse du visiteur déjà remplie.

## Tenir la liste des membres

**Membres** › **Ajouter un membre**. La liste n’est jamais visible sur le site public.
**Télécharger la liste (Excel)** produit un fichier qui s’ouvre directement dans Excel.

## Sauvegarder

Le site se sauvegarde seul chaque jour. Une fois par mois, dans **Réglages**, cliquez sur
**Télécharger une sauvegarde complète** et gardez le fichier sur une clé USB ou un disque.

## En cas de souci

| Problème | Solution |
|---|---|
| « Votre session a expiré » | Reconnectez-vous : vous revenez sur la même page. |
| Une photo d’iPhone est refusée | Sur l’iPhone : Réglages › Appareil photo › Formats › « Le plus compatible ». |
| Un article a disparu | Onglet **Corbeille** de la page **Articles**. |
| Le site ne répond plus | Attendez une minute : il redémarre tout seul. Sinon, prévenez le responsable technique. |
